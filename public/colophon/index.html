Colophon

This website is built using the Hugo Static Site Generator (SSG) with the Hugo BearCub theme. The source files are hosted on a GitHub repository, which is connected to Cloudflare. With every push from the local machine, Cloudflare automatically builds the Hugo site and publishes the public folder to learningwala.in.

Design & Typography

I made major design changes to this website in November 2026. I wanted to give the website a new personality, as a living thesis / portfolio — a quiet, letter-like feel.

Here is what you are reading:

  • Body Text & Menu: Set in Source Sans 3, a humanist sans-serif designed for comfortable long-form reading. It is set slightly lighter in dark mode so it doesn’t glare.
  • Headings & Site Name: Set in Literata, a contemporary serif designed for long-form reading. The site name is Literata Italic in semibold.
  • Quotes: Blockquotes are set in Literata Italic, and image captions in Source Sans 3 Italic.
  • Drop Caps: The large opening letters are set in Dancing Script, a handwritten font that gives them a fountain-pen feel.
  • Code & Meta: Set in Maple Mono, an open-source monospace font. You will see it in code, dates, labels and the footer.
  • Hindi & Gujarati: Set in Noto Serif Devanagari and Noto Serif Gujarati so the scripts render properly.

Technical Details

  • Colors: Light mode is a clean white page with charcoal ink, so photos and code sit on a neutral stage. Dark mode is a deep teal with a very faint grain. The palette is defined with CSS light-dark() functions, so it switches smoothly between light and dark modes, and you can also switch it by hand with the theme toggle in the footer.
  • Text Alignment: Posts and pages are left-aligned with tidy line endings. Only the homepage introduction is justified with automatic hyphenation, to mimic a printed book.
  • Numerals: Numbers use old-style figures, which blend into the text like those in a printed book.
  • Photos: Images in galleries and the selected work section are set like taped-on prints, on slightly warm paper cards against the white page, and open in a full-screen lightbox.
  • Search: Powered by Pagefind, a fast static search that runs entirely in your browser.
